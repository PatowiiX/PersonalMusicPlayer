# Personal Music Player
1. Android Studio > File > Open > carpeta PersonalMusicPlayer. Espera el Gradle Sync (requiere internet).
2. Conecta tu teléfono (Android 11+, depuración USB) y pulsa Run.
3. Acepta permisos de audio, notificaciones y Bluetooth.
4. Widget 4x1: mantén pulsada la pantalla principal > Widgets > Personal Music Player.
Datos en línea: MusicBrainz (gratis, sin API key), se consulta al abrir un álbum o la info de una canción.
